# Plans

Current and future planning material for this project.

Historical planning evidence — completed and superseded plans — lives under
[`../history/plans/`](../history/plans/). Filesystem location is a **signal** for
readers and tooling, not lifecycle authority: the authoritative plan state is the one
recorded by SOP in `.agent-sdlc/plan.meta.json`.

No plan is currently active. A completed plan's document stays here only when SOP's
archive records this path as its source; such a plan is archived and non-normative,
not active.
