# Historical plans

Completed and superseded planning documents, preserved as **evidence**.

These are historical: they are not current planning authority, and their task IDs,
acceptance criteria, completion records, and failure history are preserved verbatim.
Current and future plans live under [`../../plans/`](../../plans/). The authoritative
plan state is always the one SOP records in `.agent-sdlc/plan.meta.json`, not this
directory.
